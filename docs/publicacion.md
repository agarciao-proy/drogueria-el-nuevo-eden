# Publicación y entrega

1. Descomprimir el paquete de documentación en una carpeta local y agregar el archivo real `index.html` en esa misma carpeta. Si el HTML usa archivos externos, copiar sus carpetas sin cambiar rutas. En HTML usar rutas relativas como `./assets/logo.svg`, no rutas de tu computador. Si todo está incorporado en `index.html`, no hace falta crear `assets/`.
2. Crear un repositorio público llamado `drogueria-el-nuevo-eden` en https://github.com/new. No subir datos de la operación real ni credenciales.
3. Subir `index.html`, `README.md`, `docs/` y los recursos que existan. Si el repositorio está vacío, usar **uploading an existing file**. Si ya contiene archivos, usar **Add file → Upload files**. No subir solo el ZIP ni una carpeta contenedora que deje `index.html` fuera de la raíz. Guardar con **Commit changes**.
4. En **Settings → Pages**, elegir **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guardar. Cuando el despliegue termine, copiar la URL de **Visit site**.
5. Abrir la URL en incógnito desde un computador distinto si es posible. Verificar carga, navegación, imágenes, roles de demostración y casos de venta. Registrar únicamente lo observado.
6. En el anexo del documento maestro, incluir tres enlaces: repositorio, demo publicada y video de máximo diez minutos. Agregar el enlace al commit de la versión mostrada si se desea identificarla de forma inequívoca.
